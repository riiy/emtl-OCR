## 3. 图片来源和字体限制

项目维护者确认原始归档中的 1,100 张有标签图片及 287 张额外候选图片由 localhost 本地生成。原始生成程序已经丢失。

历史生成过程使用过操作系统自带字体或开源字体，但具体字体名称、版本和许可证无法恢复；项目不持有也不计划分发第三方字体文件。

维护者已决定公开 1,300 张图片及最终人工标签，并在数据集说明中明确披露上述不确定性。该决定表示项目选择在披露限制的前提下发布，并不表示字体来源已经完成独立法律核验。

因此：

- 不得虚构字体名称、版本或许可证。
- 不得声称已完成字体来源的独立法律核验。
- 不得将 CC BY 4.0 声明解释为对第三方字体或其他第三方权利的授权。
- 如果图片中存在受第三方权利限制的素材，披露不确定性本身不会消除该权利限制。
- 使用者应自行评估可能适用的第三方权利；本说明不构成法律意见或无侵权保证。

## 4. 公开范围和排除内容

公开数据集包含：

- 880 张训练图片。
- 220 张验证图片。
- 200 张公开固定测试图片。
- 每张图片对应的四位数字人工标签。

以下内容不公开：

- 原始 TGZ 归档及内部原始标签 CSV。
- 原始来源分类和 `sample_id`。
- 人工标注 JSONL 操作历史、私有 Manifest 和 Freeze 文件。
- 87 张未进入最终公开数据集的候选图片。
- 最初 20 张来自远程服务的探索图片。

第三方 OCR 软件、模型和依赖不复制到本仓库；Benchmark 只在隔离环境安装并调用相应版本，并保留上游许可证及归属说明。

## 5. 数据集结构和完整性

公开图片以完整 SHA-256 命名，原始 JPEG 字节保持不变。`datasets/manifest.json` 记录图片 ID、路径和固定划分；`datasets/labels.csv` 只包含 `image_id,label` 两列。

构建和审计工具验证图片 SHA-256、格式、尺寸、标签格式、数据集划分及图片/标签对应关系。该技术审计不等同于对全部标签真实性或第三方素材权利的法律审查。
