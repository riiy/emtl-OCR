# 许可证与第三方素材说明

## 1. 项目授权意向

项目已批准采用分离授权：

| 资产 | 计划许可证 |
|---|---|
| Python 源代码 | MIT |
| 文档和研究报告 | CC BY 4.0 |
| 本地生成数据集和人工标签 | CC BY 4.0 |
| 模型权重 | CC BY 4.0 |

本仓库当前阶段只加入代码许可证和授权说明。数据集与模型权重尚未发布，因此不会在尚未完成资产审查时，把 CC BY 4.0 声明误写成对所有现有文件已经完成的权利保证。

## 2. 代码许可证

仓库中的原创源代码采用 MIT License，见仓库根目录 `LICENSE`。第三方依赖仍受其各自许可证约束。

## 3. 文档、数据和模型

文档、研究报告、数据集、人工标签和模型权重计划采用 Creative Commons Attribution 4.0 International（CC BY 4.0）。

- [CC BY 4.0 官方许可证摘要](https://creativecommons.org/licenses/by/4.0/)
- [CC BY 4.0 法律文本](https://creativecommons.org/licenses/by/4.0/legalcode)

正式发布相应资产时，必须在数据集目录和模型目录附上清晰的许可证及署名信息。

## 4. 字体和生成素材限制

项目维护者确认 1,100 张训练数据及 287 张额外图片由 localhost 本地生成，最初的 100 张历史独立验收数据也由 localhost 生成。原始生成程序已经丢失。

历史生成过程使用过操作系统自带字体或开源字体，但具体字体名称、版本和许可证无法恢复；项目不持有也不计划分发第三方字体文件。

因此：

- 不得虚构字体名称或许可证。
- 不得声称已完成字体来源的独立法律核验。
- 数据集说明必须披露字体来源不确定性。
- CC BY 4.0 意向不代表项目维护者对第三方字体或其他第三方权利作出授权。
- 在公开图片之前，应尽可能通过图像特征、历史环境信息或其他可用证据完成权利风险审查，并保留审查记录。

## 5. 排除的第三方内容

最初 20 张来自远程服务的探索图片不公开。第三方 OCR 软件、模型和依赖不复制到本仓库；Benchmark 只在隔离环境安装并调用相应版本，并保留上游许可证及归属说明。

## 6. 发布门禁

数据集和模型文件只有在下列事项完成后才能进入公开 PR：

- 文件来源及用户授权声明已记录。
- 图片和标签的 SHA-256 清单已生成。
- 第三方素材和字体风险已披露并审查。
- 不含账号、Cookie、Token、会话标识或其他敏感信息。
- 每个目录的许可证和署名说明明确。
- 公开文件与训练、验证、盲测数据划分一致。

本说明是项目的许可证管理记录，不构成法律意见，也不保证未知第三方素材不存在权利限制。
