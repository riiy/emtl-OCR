## P2 — 数据集建设与冻结

**当前分支：** feat/p2-dataset-blindtest-labeling

已实现/正在实现：
- 固定种子 20261127 的源分层 880/220 训练/验证划分生成器。
- 从 287 张未引用图片中固定抽取 200 张，保留 87 张备用。
- 本地离线人工标注工具：不显示 OCR 预测、四位 ASCII 数字、保留前导零、跳过及断点续标。
- 标签冻结工具：验证 200 条有效标签、图片 ID/路径/哈希及四位字符串，并输出 SHA-256。
- P2 操作指南和数据集协议。

P2 剩余验收：
1. 在真实归档上运行数据准备脚本并核对清单。
2. 执行自动化测试及人工标注工具离线启动验证。
3. 维护者亲自完成 200 张人工标注；跳过项由 87 张备用图片补足。
4. 冻结标签、进度、manifest 和 SHA-256。
5. 确认 87 张备用图未进入训练、验证或 Benchmark。

P2 不运行 OCR Benchmark，不根据预测修改标签。源图片、标签、进度和模型不在本 PR 上传。

## P3 — PyTorch 训练重建

最多三个模型：原始 Baseline、更小 CNN、有限通道调整 CNN。使用同一 880/220 划分，有限数据增强，仅以内部验证集选择。保存配置、日志、Checkpoint 和环境版本。新实验标记为 reconstructed experiment。

## P4 — 推理与离线 Benchmark

提供独立纯 Python + Pillow 推理；冻结模型后在同一 200 张盲测集上比较 tiny-CNN、ddddOCR 1.4.11 和 1.6.1。报告整图、字符和前导零指标。90% 未通过时照实报告，不使用同一测试集继续调参。

## P5 — 开源交付与独立 Review

完成代码、数据、模型、文档许可证审查，验证复现流程，完成独立 Review 并创建交付 PR。合并、Tag 和发布需另行批准。

## 分支与 PR 规则

所有修改从最新 main 创建独立分支；不直接向 main 推送；每阶段通过 PR 提交；创建 PR 不代表获得合并授权；不自动合并、不自动创建发布 Tag、不自动发布 PyPI。
