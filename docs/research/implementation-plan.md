## P2 — 数据集建设、人工标注与公开数据

**状态：已完成，PR #4 已合并。**

已完成：
- 固定种子 20261127 的来源分层 880/220 训练/验证划分。
- 从 287 张未引用图片候选中最终获得 200 张人工标注测试图片。
- 本地离线 Web 标注工具：不显示 OCR 预测、四位 ASCII 数字、保留前导零、跳过及断点续标。
- 标签冻结：200 条唯一有效标签，保留 5 张跳过记录和 206 条操作事件。
- 冻结文件中的标签和进度 SHA-256 已验证。

本次公开数据整理：
- 将 1,100 张原始有标签图片和 200 张人工标注测试图片统一为 1,300 张公开图片。
- 图片以完整 SHA-256 命名，原始 JPEG 字节不变。
- 统一 Manifest 记录图片身份和固定划分。
- 统一 `labels.csv` 作为唯一权威标签源。
- 不公开原始来源分类、样本 ID、原始归档、标注操作日志和 87 张未公开候选图片。
- 增加自动构建、审计工具及测试。
- 披露字体来源不确定性和第三方权利限制。

P2 不运行 OCR Benchmark，不根据预测修改标签。

## P3 — PyTorch CPU 训练重建

**状态：实施中；正式 18 次训练尚未运行。**

- 三个模型 A/B/C，参数量分别为 83,888、29,812、83,736。
- 使用固定 880/220 train/validation 划分，test split 不参与训练或模型选择。
- 固定 AdamW、训练预算、Early Stopping、数据增强和三个随机种子。
- conda-forge：Python 3.12、PyTorch 2.14.1 CPU Generic；Ubuntu x86_64 正式训练，Intel Mac x86_64 完整复现。
- Ubuntu 9 次、Intel Mac 9 次，共 18 次；保存逐 Epoch 日志、Checkpoint、配置、环境信息和 SHA-256。
- 使用验证集均值、标准差和 1 个百分点的简化模型选择规则；胜出架构使用中位数 Seed Checkpoint。
- CI 运行环境锁定求解和合成数据 Smoke Test，不执行完整训练。
- 新实验标记为 reconstructed experiment，不声称历史精确复现。

## P4 — 推理与公开固定测试集评估

提供独立纯 Python + Pillow 推理；冻结模型后在同一 200 张公开固定测试集上比较 tiny-CNN、ddddOCR 1.4.11 和 1.6.1。报告整图、字符和前导零指标。90% 未通过时照实报告，不使用同一测试集继续调参。

由于测试集标签已经公开，不再称为保密盲测集；其成员关系仍然固定，不能参与训练、模型选择或调参。

## P5 — 开源交付与独立 Review

完成代码、数据、模型、文档许可证审查，验证复现流程，完成独立 Review 并创建交付 PR。合并、Tag 和发布需另行批准。

## 分支与 PR 规则

所有修改从最新 main 创建独立分支；不直接向 main 推送；每阶段通过 PR 提交；创建 PR 不代表获得合并授权；不自动合并、不自动创建发布 Tag、不自动发布 PyPI。
