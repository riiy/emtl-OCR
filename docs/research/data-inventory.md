## 4. 公开数据集

公开数据集由 1,100 张原始有标签图片和 200 张人工标注测试图片组成：

| Split | 图片数 | 用途 |
|---|---:|---|
| train | 880 | 模型训练 |
| validation | 220 | 模型选择和调参 |
| test | 200 | 公开固定最终评估 |
| **合计** | **1,300** | |

训练/验证成员关系沿用历史固定随机种子 `20261127` 和来源分层 80/20 划分过程。来源分类不公开，因此外部不能仅凭种子和方法说明重新生成该划分；`datasets/manifest.json` 中的实际成员关系是权威依据。

测试集成员关系固定。Manifest 记录测试成员集合的 SHA-256，并保存初始各 split 成员清单，以便审计工具检测基线样本被删除、移动或向测试集新增样本。

## 5. 公开文件格式

```text
datasets/
├── images/
│   └── <完整64位SHA256>.jpg
├── manifest.json
├── labels.csv
├── README.md
└── LICENSE
```

- 图片文件名使用完整 64 位 SHA-256。
- 原始归档中的 JPEG 字节保持不变，仅将 `.img` 扩展名改为 `.jpg`。
- Manifest 图片记录仅包含 `image_id`、`path` 和 `split`。
- `image_id` 本身就是完整 SHA-256，不重复保存独立哈希字段。
- CSV 只有 `image_id,label` 两列，标签为四位字符串并保留前导零。
- 不公开原始来源分类、样本 ID、原始标签 CSV、标注进度 JSONL、冻结私有文件、87 张未公开候选图片或 20 张远程来源探索图片。

## 6. 可复现构建和审计

维护者构建命令：

```bash
python tools/build_public_dataset.py \
  --archive /path/to/captcha_train_1100.tgz \
  --blind-labels /path/to/blind-test-labels.csv \
  --blind-progress /path/to/blind-test-progress.jsonl \
  --blind-freeze /path/to/blind-test-freeze.json \
  --output datasets
```

构建工具验证源归档和原始标签 CSV 的固定 SHA-256、200 条最终人工标签、Freeze 文件中的标签及进度哈希、事件序列和最终状态、每张图片的完整 SHA-256 及 JPEG 属性。构建输出目录必须不存在；工具不会覆盖已有数据或人工修正标签。

公开数据集审计：

```bash
python tools/audit_dataset.py \
  --dataset datasets \
  --verify-images \
  --verify-labels \
  --verify-splits
```

审计检查图片缺失、额外文件、重复 ID、哈希、JPEG 格式与尺寸、CSV 字段、标签格式、图片/标签对应关系、基线成员关系、测试集固定成员及新增图片只能进入训练集或验证集。

## 7. 研究和权利限制

- 200 张测试图片和标签已经公开，因此它们是 **Public Fixed Test Set**，不是保密盲测集。仍须在模型冻结后进行正式评估，不得用其训练或调参。
- 原始来源分类未公开。公开的 seed 和分层方法说明不足以单独重建训练/验证划分；Manifest 成员关系为最终依据。
- 原始图片生成程序已丢失。历史使用过操作系统自带字体或开源字体，但具体名称、版本和许可证无法恢复。
- 数据集许可证说明披露字体来源不确定性；该说明不构成独立法律核验，也不授予第三方字体或其他第三方权利。
- 本审计证明归档、图片、标签和数据结构的一致性，不等同于逐张重新判定全部人工标签的视觉正确性，也不构成法律意见。
