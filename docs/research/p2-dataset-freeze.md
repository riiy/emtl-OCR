## 4. 本地人工标注工具

工具：tools/annotate_blind_test.py

仅使用 Python 标准库；浏览器直接显示本地 JPEG，不加载外部 JS/CSS，也不调用 OCR。HTTP 服务固定绑定 127.0.0.1。

### 启动

    python tools/annotate_blind_test.py \
      --archive ~/captcha_train_1100.tgz \
      --manifest datasets/manifests/blind-test-candidates.json.gz

默认打开 http://127.0.0.1:8765/。如果端口已占用，可用 --port 8766。停止服务按 Ctrl+C；已保存进度不会丢失。

### 标注约束

- 每张图片独立人工输入恰好四位数字，保留前导零，例如 0037。
- 不显示 tiny-CNN、ddddOCR 或其他模型预测。
- 输入中的 0–3 位草稿会自动保存；输入完整四位数字后自动保存为有效标签，也可使用“保存并下一张”。
- 支持上一张、下一张待标注和键盘快捷键。
- 无法辨认必须填写原因，状态记为 skipped，不作为有效标签。
- 关闭后重新运行相同命令，可从本地状态文件恢复。
- 达到 200 个有效标签后，可回看和修正已有标签；不能新增第 201 个标签。
- 点击冻结后，工具按候选队列顺序选取前 200 个有效标签，冻结状态不可修改。

### 本地输出

默认工作目录为 .local-data/p2-blind-test/，已加入 .gitignore：

    .local-data/p2-blind-test/
    ├── annotations.json
    ├── images/
    └── frozen/
        ├── images/
        ├── blind_test_labels.csv
        └── blind_test_manifest.json

annotations.json 是自动保存的本地进度；images/ 是从原归档提取的候选图片。冻结目录包含最终 200 张图片、四位字符串标签和抽样/跳过/替补记录。

不要把 .local-data/ 上传到 GitHub。完成标注后，先将 blind_test_labels.csv 和 blind_test_manifest.json 提供给项目维护者进行结构、哈希、样本数及标签格式复核；图片暂时留在本机。

## 5. 生成/复核清单

    python tools/prepare_dataset.py \
      --archive ~/captcha_train_1100.tgz \
      --output-dir datasets/manifests \
      --gzip

该命令重新检查 1,100 条标签引用、图片 SHA-256、未引用候选图片，并重建三个 JSON 清单。--gzip 会确定性生成压缩的 .json.gz 清单。默认种子固定为 20261126 和 20261127。如需输出普通 JSON，可省略 --gzip。

如需重新生成已冻结的数据版本，不应覆盖原清单；应创建新的数据版本并记录原因。
