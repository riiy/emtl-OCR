# emtl-OCR

**一个独立、可复现的轻量数字图像 OCR 研究项目。**

emtl-OCR 记录并复现一项面向四位数字合成图像的 OCR 研究：从冻结数据集、人工标注、PyTorch 训练，到纯 Python + Pillow 推理，以及与 ddddOCR 的离线对比。

> **项目状态：P2 数据集工具已实现；本地 Web 盲测标注工具正在 PR 验证，200 张人工标注尚未完成。** 当前仓库尚未发布可安装的软件包、图片数据或模型权重。历史成绩不是本仓库新实验结果。

## 研究目标

- 公开可合法再分发的本地生成图像、人工标签和数据处理记录。
- 重建 PyTorch 训练流程，记录配置、随机种子、日志和检查点。
- 在有限范围内比较最多三个 CNN 架构（包含历史 tiny-CNN 基线）。
- 提供独立于 emtl 的纯 Python + Pillow 推理实现。
- 在同一组人工标注盲测图片上比较 tiny-CNN、ddddOCR 1.4.11 和 1.6.1。
- 发布可检查的逐张预测、评估脚本和研究局限。

本项目是离线图像识别研究，不包含验证码抓取、登录自动化、远程认证接口调用或反机器人机制规避功能。

## 历史基线（不可视为新实验）

| 实验 | 历史结果 | 证据限制 |
|---|---:|---|
| tiny-CNN 内部验证 | 216/220（98.18%） | 原始训练脚本和日志未恢复 |
| tiny-CNN 独立验收 | 96/100（96%） | 有逐张预测和标签记录，但原图缺失 |
| ddddOCR 独立验收 | 66/100（66%） | 历史 JSON 未记录准确版本 |
| tiny-CNN 前导零样本 | 10/10 | 历史验收记录 |

## 数据概况

恢复的训练归档包含 1,100 条标签记录（1,000 ACCEPTED、30 REJECTED、70 SKIPPED_INVALID_FORMAT）和 1,387 张 101×36 JPEG 图片，其中 287 张未被训练标签清单引用。项目维护者确认这 287 张图片由 localhost 生成且未参与此前实验；这是来源声明，图片数量及哈希关系可由归档独立核验。

最初 20 张远程来源探索图片不公开，也不纳入正式数据集。

## 独立性与研究诚信

本仓库独立于 riiy/emtl，不修改或依赖 emtl 运行时代码。第一阶段不发布 PyPI 包。推理运行时目标为 Pillow + Python 标准库；PyTorch 仅用于训练。

- 区分历史报告、实际恢复文件、用户提供的来源声明和新实验结果。
- 不伪造缺失的原始训练脚本、检查点或测试图片。
- 新训练标记为重建实验，不声称是历史训练的精确复现。
- 新盲测集在模型冻结前不提供预测结果，不用于调参。
- 即使新盲测准确率低于 90%，也如实发布结果，不对同一测试集继续调参。
