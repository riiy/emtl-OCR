# emtl-OCR

**一个独立、可复现的轻量数字图像 OCR 研究项目。**

emtl-OCR 记录并复现一项面向四位数字合成图像的 OCR 研究：从冻结数据集、人工标注、PyTorch 训练，到纯 Python + Pillow 推理，以及与 ddddOCR 的离线对比。

> **项目状态：研究资料恢复与基础文档阶段。** 当前仓库尚未发布可安装的软件包，也尚未发布训练数据或模型权重。请勿将历史实验成绩视为本仓库已完成的可复现实验结果。

## 研究目标

- 公开可合法再分发的本地生成图像、人工标签和数据处理记录。
- 重建 PyTorch 训练流程，记录配置、随机种子、日志和检查点。
- 在有限范围内比较最多三个 CNN 架构（包含历史 tiny-CNN 基线）。
- 提供独立于 `emtl` 的纯 Python + Pillow 推理实现。
- 在同一组人工标注盲测图片上比较 tiny-CNN、ddddOCR 1.4.11 和 1.6.1。
- 发布可检查的逐张预测、评估脚本和研究局限。

本项目是离线图像识别研究，不包含验证码抓取、登录自动化、远程认证接口调用或反机器人机制规避功能。

## 已恢复的历史基线

历史会话记录了以下结果：

| 实验 | 历史结果 | 证据限制 |
|---|---:|---|
| tiny-CNN 内部验证 | 216/220（98.18%） | 历史报告；原始训练脚本和日志尚未恢复 |
| tiny-CNN 独立验收 | 96/100（96%） | 有逐张预测和标签记录，但 100 张原图缺失 |
| ddddOCR 独立验收 | 66/100（66%） | 历史 JSON 未记录准确版本 |
| tiny-CNN 前导零样本 | 10/10 | 历史验收记录 |

这些数字是**历史报告结果**，不是本仓库新训练或新盲测的结果。新实验会重新建立数据划分、训练模型，并使用新的 200 张盲测集。

## 已恢复数据概况

当前恢复的训练归档包含：

- 1,100 条四位数字标签记录：1,000 ACCEPTED、30 REJECTED、70 SKIPPED_INVALID_FORMAT。
- 1,387 张有效的 101×36 JPEG 图片，其中 287 张未被训练标签清单引用。
- 100 条历史人工审核记录和 100 条历史预测记录。
- 287 张额外图片由项目维护者确认是本地生成且未参与此前训练、验证或调参；该来源说明属于维护者提供的 provenance 声明。

新盲测计划：从 287 张额外图片中固定随机抽取 200 张，由维护者亲自标注并冻结标签，剩余 87 张作为无标签备用数据。该过程尚未完成。

最初 20 张来自远程服务的早期探索图片不公开，也不纳入正式数据集。

详细审计见 [数据清单](docs/research/data-inventory.md) 和 [历史证据记录](docs/research/historical-evidence.md)。

## 独立性

本仓库独立于 [riiy/emtl](https://github.com/riiy/emtl)，不修改或依赖 emtl 的运行时代码。历史冻结推理实现和模型权重曾集成于 emtl，可作为研究证据参考，但新仓库将独立重建训练、推理和评估实现。

第一阶段不发布 PyPI 包。推理运行时目标为 Pillow + Python 标准库；PyTorch 仅用于训练和实验。安装体积和推理延迟作为参考指标，不设硬性门槛。

## 研究诚信

- 区分历史报告、实际恢复文件、用户提供的来源声明和新实验结果。
- 不伪造缺失的原始训练脚本、检查点或测试图片。
- 新训练标记为重建实验，不声称是历史训练的精确复现。
- 新盲测集在模型冻结前不提供预测结果，不用于调参。
- 即使新盲测准确率低于 90%，也如实发布结果，不对同一测试集继续调参。
