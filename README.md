# emtl-OCR

**一个独立、可复现的轻量数字图像 OCR 研究项目。**

emtl-OCR 记录并复现一项面向四位数字合成图像的 OCR 研究：从固定数据集、人工标注、PyTorch 训练，到纯 Python + Pillow 推理，以及与 ddddOCR 的离线对比。

> **项目状态：P2 数据准备、人工标注、冻结及公开数据整理已完成（PR #4 已合并）；P3 训练代码与环境重建正在实施，正式训练尚未开始。** 本次公开数据集包含 1,300 张图片和最终标签。历史成绩不是本仓库新实验结果。

## 研究目标

- 发布 1,300 张本地生成图像及其人工标签，并明确披露字体来源和第三方权利的不确定性。
- 重建 PyTorch 训练流程，记录配置、随机种子、日志和检查点。
- 在有限范围内比较最多三个 CNN 架构（包含历史 tiny-CNN 基线）。
- 提供独立于 emtl 的纯 Python + Pillow 推理实现。
- 在同一组 200 张公开固定测试图片上比较 tiny-CNN、ddddOCR 1.4.11 和 1.6.1。
- 发布可检查的逐张预测、评估脚本和研究局限。

本项目是离线图像识别研究，不包含验证码抓取、登录自动化、远程认证接口调用或反机器人机制规避功能。

## 历史基线（不可视为新实验）

| 实验 | 历史结果 | 证据限制 |
|---|---:|---|
| tiny-CNN 内部验证 | 216/220（98.18%） | 原始训练脚本和日志未恢复 |
| tiny-CNN 独立验收 | 96/100（96%） | 有逐张预测和标签记录，但原图缺失 |
| ddddOCR 独立验收 | 66/100（66%） | 历史 JSON 未记录准确版本 |
| tiny-CNN 前导零样本 | 10/10 | 历史验收记录 |

## 数据集

公开数据位于 [`datasets/`](datasets/)，包含：

| Split | 图片数 | 用途 |
|---|---:|---|
| train | 880 | 模型训练 |
| validation | 220 | 模型选择和调参 |
| test | 200 | 公开固定最终评估 |
| **合计** | **1,300** | |

图片统一存放在 `datasets/images/`，文件名为完整 64 位 SHA-256；`datasets/manifest.json` 记录图片身份、相对路径和固定划分；`datasets/labels.csv` 是唯一权威标签源，仅包含 `image_id,label` 两列。标签必须作为四位字符串处理，保留前导零。

原始归档包含 1,387 张 JPEG 图片。1,100 张原始有标签图片用于训练/验证划分，另有 200 张人工标注图片作为公开固定测试集。其余 87 张候选图片不公开。最初 20 张来自远程服务的探索图片不属于本数据集，也不公开。

训练/验证划分历史上使用来源分层 80/20 方法；来源分类和样本 ID 不公开。公开 Manifest 中的实际成员关系是权威划分依据，随机种子和方法说明不能单独重建隐藏的分层过程。

**测试集说明：** 200 张测试图片及其标签现在均为公开数据。它们仍保持固定测试集成员身份，但不再是保密盲测集。模型冻结前不得查看测试集评估结果，也不得用测试集进行训练、架构选择或超参数调整。

完整数据结构、审计命令和权利限制见 [`datasets/README.md`](datasets/README.md)。

## P3 训练重建

P3 使用固定的 A/B/C 三个 CNN 候选模型和三个随机种子。Ubuntu x86_64 是正式训练环境；Intel Mac x86_64 完整运行相同的九次训练，作为跨平台复现验证。两个平台合计 18 次训练。

| 模型 | 卷积通道 | FC1 | 参数量 |
|---|---|---:|---:|
| A | 3→8→16→24 | 128 | 83,888 |
| B | 3→6→12→16 | 64 | 29,812 |
| C | 3→8→16→32 | 96 | 83,736 |

固定环境为 conda-forge、Python 3.12、PyTorch 2.14.1 CPU Generic。训练配置、增强顺序、Checkpoint 规则、跨平台验收和命令见 [P3 训练协议](docs/research/p3-training-protocol.md)。

```bash
conda env create -f environment.yml
conda activate emtl-ocr-p3
python tools/train_models.py
python tools/audit_training_runs.py --root outputs/p3 --output outputs/p3/audit.json
```

P3 只使用 train/validation split，不读取 Test 指标进行模型选择。200 张图片及标签是公开固定测试集，正式评估留待 P4 的模型冻结之后。

## 独立性与研究诚信

本仓库独立于 riiy/emtl，不修改或依赖 emtl 运行时代码。第一阶段不发布 PyPI 包。推理运行时目标为 Pillow + Python 标准库；PyTorch 仅用于训练。

- 区分历史报告、实际恢复文件、用户提供的来源声明和新实验结果。
- 不伪造缺失的原始训练脚本、检查点或测试图片。
- 新训练标记为重建实验，不声称是历史训练的精确复现。
- 公开固定测试集不用于训练、模型选择或调参；正式评估应在模型冻结后进行。
